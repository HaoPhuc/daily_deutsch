## Theory

### A1-G01 Pronunciation and the alphabet
German is spelled almost exactly as it sounds. Learn a handful of rules and you can read any word aloud.

**The alphabet** (say the letter names out loud):

| Letter | Name | Letter | Name | Letter | Name |
|---|---|---|---|---|---|
| A | ah | J | yot | S | ess |
| B | beh | K | kah | T | teh |
| C | tseh | L | ell | U | oo |
| D | deh | M | emm | V | fow |
| E | eh | N | enn | W | veh |
| F | eff | O | oh | X | iks |
| G | geh | P | peh | Y | üpsilon |
| H | hah | Q | koo | Z | tset |
| I | ee | R | err | | |

Extra letters: **ä** (like *e* in "bed"), **ö** (say "eh" with rounded lips), **ü** (say "ee" with rounded lips), **ß** = "ss" (name: *eszett*).

**Sounds that differ from English:**

| Spelling | Sounds like | Example |
|---|---|---|
| ei | "eye" | *heißen, nein* |
| ie | "ee" | *Sie, vier* |
| eu, äu | "oy" | *Deutsch, Häuser* |
| w | English v | *wie, Wasser* |
| v | English f (usually) | *Vater, vier* |
| z | "ts" | *Zeit, zwei* |
| j | English y | *ja, Jahr* |
| sch | "sh" | *Schule, schön* |
| st-, sp- (word start) | "sht", "shp" | *Straße, Sport* |
| ch after a, o, u | throaty, like Scottish "loch" | *auch, Buch* |
| ch after e, i, ä, ö, ü | soft hiss, like "h" in "huge" | *ich, nicht* |
| s before a vowel | English z | *Sie, sehr* |
| -b, -d, -g at word end | p, t, k | *ab, und, Tag* |

**Examples**
- *Ich heiße Phuc.* (My name is Phuc.)
- *Wie geht es Ihnen?* (How are you? — formal)
- *Das ist sehr schön.* (That is very nice.)
- *Ich spreche ein bisschen Deutsch.* (I speak a little German.)

**Pitfalls**
1. **ei vs ie:** read the *second* letter in English. *ei* → "i" → "eye"; *ie* → "e" → "ee". So *Wien* = "veen", *Wein* = "vine".
2. **w is v, v is f:** *wie* is "vee", not "wee".
3. **No silent letters:** the *e* at the end is spoken (*Name* = "NAH-meh"), and *k* in *Knie* is pronounced.

### A1-W01 Greetings and introducing yourself

| German | English |
|---|---|
| Hallo! / Hi! | Hello! / Hi! (informal) |
| Guten Morgen! | Good morning! |
| Guten Tag! | Good day / Hello (formal) |
| Guten Abend! | Good evening! |
| Tschüss! / Auf Wiedersehen! | Bye! (informal) / Goodbye! (formal) |
| Wie geht es Ihnen? / Wie geht's? | How are you? (formal / informal) |
| Danke, gut. / Sehr gut, danke. | Fine, thanks. / Very good, thanks. |
| Ich heiße … / Mein Name ist … | My name is … |
| Ich komme aus … | I come from … |
| Ich wohne in … | I live in … |
| der Name, die Namen | name |
| der Herr, die Herren | Mr / gentleman |
| die Frau, die Frauen | Mrs / woman |

**Sie** (capital S) = formal "you" for strangers, teachers, Herr/Frau. **du** = informal "you" for friends, family, other students.

## Tasks

### 1. Read a dialogue · Lesen
~6 min. Read it aloud once, then answer in English.

> **Frau Weber:** Guten Morgen, Herr Lang! Wie geht es Ihnen?
> **Herr Lang:** Guten Morgen, Frau Weber. Danke, gut. Und Ihnen?
> **Frau Weber:** Sehr gut, danke. Das ist Lukas. Er ist Student.
> **Lukas:** Hallo! Ich heiße Lukas. Ich komme aus Wien.
> **Herr Lang:** Freut mich, Lukas!
> **Lukas:** Tschüss, Frau Weber! Auf Wiedersehen, Herr Lang!

a) What time of day is it?
b) Do Frau Weber and Herr Lang use *Sie* or *du*? Which words show it?
c) Where does Lukas come from?
d) Lukas says goodbye in two different ways. Why?
